## 1. 用户旅程地图

### 1.1 完整用户流程

```
启动游戏 → 启动画面 → 主菜单 → 关卡选择 → 游戏主界面 → 结算 → 下一关/重玩
```

```
瞄准阶段 → 发射阶段 → 等待稳定 → 检查结果 → [继续发射 | 关卡结束]
```

## 3. 交互设计

### 3.1 弹弓操作方式

**发射流程:**
1. 点击小鸟 → 小鸟高亮，提示可拖拽
2. 拖拽瞄准 → 显示预测轨迹
3. 释放发射 → 小鸟沿抛物线飞行
4. 飞行中 → 显示轨迹尾迹
5. 等待稳定 → 所有物体静止后判定结果

### 3.2 操作参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 最小拖拽距离 | 30px | 小于此值不发射 |
| 最大拖拽距离 | 150px | 限制最大力度 |
| 拖拽角度范围 | -80° ~ 80° | 限制发射角度 |
| 预测轨迹点数 | 10个 | 显示10个预测点 |

### 3.3 触控/鼠标交互规范

| 交互类型 | 响应时间 | 反馈 |
|----------|----------|------|
| 按钮悬停 | < 50ms | 光标变化 + 缩放 |
| 按钮点击 | < 50ms | 音效 + 视觉 |
| 拖拽开始 | < 50ms | 音效 + 高亮 |
| 拖拽中 | 实时 | 轨迹预测 |
| 释放 | < 50ms | 发射音效 |

## 4. 视觉规范

### 4.1 色彩方案

**背景渐变:**
- 天空顶部: #87CEEB (天蓝)
- 天空底部: #B0E0E6 (粉蓝)
- 地面: #228B22 (森林绿)

**角色色彩:**
- 红鸟: #FF0000 (愤怒红)
- 蓝鸟: #1E90FF (道奇蓝)
- 黄鸟: #FFD700 (金黄)
- 猪: #90EE90 (浅绿)

**材质色彩:**
- 木材: #8B4513 (马鞍棕)
- 石材: #708090 (石板灰)
- 玻璃: #ADD8E6 (浅蓝透明)

**UI色彩:**
- 主按钮: #4CAF50 (绿色)
- 危险操作: #F44336 (红色)
- 强调: #FFC107 (琥珀)
- 文字: #333333 (深灰)

### 4.2 字体规范

**字体选择:**
- 标题: 'Fredoka One' - 圆润、有趣、游戏感
- 正文: 'Nunito' - 清晰、易读、友好
- 数字: 'Orbitron' - 数字清晰、有科技感

**字号规范:**
- 大标题: 48px
- 中标题: 32px
- 按钮: 24px
- 正文: 18px
- 小字: 14px

### 4.3 UI元素尺寸规范

**按钮尺寸:**
- 大按钮: 200 × 60px, 圆角30px
- 中按钮: 150 × 50px, 圆角25px
- 小按钮: 50 × 50px, 圆形

**最小触摸目标:** 44 × 44px (iOS/Android规范)

### 4.4 响应式设计

**断点设计:**
- 移动端: < 768px (全屏游戏)
- 平板: 768px - 1024px (居中显示)
- 桌面: > 1024px (居中 + 背景装饰)

## 5. 动画和反馈

### 5.1 小鸟发射动画

```
发射动画序列:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 拖拽阶段:
   😠 → 😤 (表情变化)
   弹弓拉伸动画
   预测轨迹淡入

2. 发射瞬间:
   😤 → 😠 (恢复表情)
   弹弓回弹动画 (100ms)
   发射音效

3. 飞行阶段:
   😠 旋转 (根据速度)
   轨迹尾迹 (淡出效果)
   风声效果

4. 碰撞阶段:
   😠 → 💥 (碰撞特效)
   粒子效果
   碰撞音效
```

### 5.2 碰撞反馈

| 碰撞类型 | 视觉反馈 | 音效 | 震动 |
|----------|----------|------|------|
| 木块破碎 | 木屑粒子 + 碎裂 | 啪嗒声 | 轻微 |
| 石块碰撞 | 火星粒子 | 砰声 | 中等 |
| 玻璃破碎 | 玻璃碎片粒子 | 碎裂声 | 轻微 |
| 猪被消灭 | 绿色粒子 + 星星 | 哼叫声 | 中等 |

### 5.3 得分动画

```
得分弹出动画:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

位置: 碰撞点
     ┌───────┐
     │ +500  │  ← 弹出
     └───────┘
         ↑
        飞出并淡出 (500ms)

得分累加动画:
当前分数: 1000
     ↓
   1,500  ← 数字滚动动画 (200ms)
```

### 5.4 UI过渡动画

| 过渡 | 动画类型 | 持续时间 |
|------|----------|----------|
| 场景切换 | 淡入淡出 | 300ms |
| 按钮悬停 | 缩放1.05 | 100ms |
| 按钮点击 | 缩放0.95 | 50ms |
| 弹窗打开 | 从中心放大 | 200ms |
| 弹窗关闭 | 向中心缩小 | 150ms |
| 星星获得 | 弹跳动画 | 500ms/颗 |

## 6. 可访问性

### 6.1 操作提示

**新手引导流程:**
1. 首次进入游戏 → 显示操作教程
2. 高亮弹弓区域 → "点击并拖拽小鸟"
3. 显示预测轨迹 → "松开发射"
4. 首次成功发射 → 鼓励提示

**提示样式:**
- 半透明遮罩 + 高亮目标区域
- 手指动画指示操作方向
- 文字提示 (简洁明了)

### 6.2 视觉辅助

- 高对比度模式 (可选)
- 色盲友好模式 (可选)
- 文字阴影增强可读性

## 技术架构

### 模块化设计
```
src/
├── config.js           # 游戏配置常量
├── main.js            # 主入口和事件处理
├── block/block.js     # 方块类和工厂
├── game/
│   ├── game.js       # 游戏引擎主循环
│   ├── grid.js       # 游戏网格管理
│   └── score.js      # 分数和等级管理
├── render/canvas-renderer.js  # Canvas渲染系统
└── ui/ui-controller.js       # UI交互控制
```

### 关键技术
- 纯JavaScript/ES6+（无框架依赖）
- HTML5 Canvas 2D渲染
- CSS3动画和渐变效果
- ES6模块系统
- localStorage数据持久化
- 响应式CSS设计

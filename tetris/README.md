# 俄罗斯方块游戏

一个使用HTML5 Canvas和JavaScript开发的经典俄罗斯方块游戏。

## 功能特点

- 🎮 完整的俄罗斯方块游戏逻辑
- 🎨 现代化的UI设计，支持响应式布局
- ⌨️ 键盘控制（方向键、空格、P键等）
- 📱 触摸屏支持（移动设备）
- 📊 分数统计和最高分记录
- ⚡ 60fps流畅动画效果
- 🔄 方块预览和阴影预测

## 游戏控制

### 键盘控制
- **← →** : 左右移动方块
- **↑** : 旋转方块
- **↓** : 加速下落
- **空格** : 立即下落（硬降）
- **P** : 暂停/继续游戏
- **R** : 重新开始游戏
- **Enter** : 开始游戏

### 触摸屏控制（移动设备）
- **左右滑动** : 移动方块
- **上下滑动** : 旋转和加速下落
- **双击** : 立即下落（硬降）

## 计分规则

- 消单行: 100 × 等级 分
- 消双行: 300 × 等级 分
- 消三行: 500 × 等级 分
- 消四行: 800 × 等级 分
- 软降（加速下落）: 每格1分
- 硬降（立即下落）: 每格2分

## 等级系统

- 初始等级: 1级
- 每消除10行升一级
- 最大等级: 20级
- 随着等级提高，方块下落速度加快

## 技术架构

### 前端技术栈
- HTML5 Canvas 渲染
- 纯JavaScript/ES6+（无框架依赖）
- CSS3 动画和渐变效果
- 响应式设计

## 运行方式

### 在线运行
先运行后端服务器：py -3 .\run_server.py（默认会直接打开游戏页面）
直接打开 `index.html` 文件即可开始游戏。

### 本地开发
1. 克隆或下载项目文件
2. 用浏览器打开 `index.html`
3. 开始游戏！

### 注意事项
- 游戏使用localStorage保存最高分
- 需要现代浏览器支持HTML5 Canvas
- 推荐使用Chrome、Firefox、Edge等现代浏览器

## 浏览器兼容性

- Firefox 55+

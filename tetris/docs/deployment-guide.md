# 俄罗斯方块游戏部署指南

## 概述
本指南详细介绍如何部署和运行俄罗斯方块游戏。游戏采用纯前端技术栈，无需后端服务器支持。

## 系统要求

### 硬件要求
- **内存**: 至少512MB RAM
- **存储**: 至少5MB可用空间
- **显示**: 支持WebGL或Canvas的显卡

### 软件要求
- **操作系统**: Windows 10+, macOS 10.14+, Linux, iOS 11+, Android 7+
- **浏览器**: Chrome 60+, Firefox 55+, Safari 11+, Edge 79+
- **网络**: 仅用于加载外部字体（可选）

## 部署方式

### 方式1：本地直接运行（推荐）
最简单的部署方式，适用于个人使用或演示。

**步骤：**
1. 复制整个 `tetris` 文件夹到目标计算机
2. 双击 `index.html` 文件
3. 浏览器会自动打开并运行游戏

**优点：**
- 无需配置
- 无需网络连接
- 适合快速演示

### 方式2：静态Web服务器部署
适用于企业内网或局域网分享。

**使用Python简单服务器：**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**使用Node.js简单服务器：**
```bash
# 安装http-server
npm install -g http-server

# 启动服务器
http-server -p 8080
```

**访问地址：**
```
http://localhost:8000
或
http://[服务器IP]:8000
```

### 方式3：云服务器部署
适用于公开访问。

**推荐平台：**
- GitHub Pages (免费)
- Netlify (免费)
- Vercel (免费)
- AWS S3 + CloudFront
- 阿里云OSS
- 腾讯云COS

#### GitHub Pages部署步骤：
1. 创建GitHub仓库
2. 上传所有文件到仓库
3. 进入仓库设置 → Pages
4. 选择分支和根目录
5. 保存，等待部署完成

#### Netlify部署步骤：
1. 注册Netlify账户
2. 拖放项目文件夹到部署区域
3. 自动部署，获取URL

## 配置选项

### 游戏配置调整
可以修改 `src/config.js` 文件来调整游戏参数：

```javascript
// 游戏区域大小
GRID_WIDTH: 10,          // 游戏区域宽度（列数）
GRID_HEIGHT: 20,         // 游戏区域高度（行数）
CELL_SIZE: 40,           // 每个格子的像素大小

// 游戏速度配置
INITIAL_SPEED: 1000,     // 初始下落速度（毫秒）
MIN_SPEED: 50,           // 最小下落速度
SPEED_DECREMENT: 50,     // 每级速度减少量

// 计分规则
SCORE_SINGLE_LINE: 100,   // 消单行得分
SCORE_DOUBLE_LINE: 300,   // 消双行得分
SCORE_TRIPLE_LINE: 500,   // 消三行得分
SCORE_TETRIS_LINE: 800,   // 消四行得分

// 控制键配置
CONTROLS: {
    MOVE_LEFT: ['ArrowLeft', 'KeyA'],
    MOVE_RIGHT: ['ArrowRight', 'KeyD'],
    // ... 其他控制键
}
```

### 主题定制
可以修改 `style.css` 文件来调整UI样式：

/* 主要颜色主题 */

## 浏览器兼容性处理

### 已知兼容性问题
1. **IE浏览器**: 不支持ES6模块，需要转译
2. **旧版浏览器**: 可能需要polyfill
3. **移动设备**: 触摸事件需要特定处理

### 兼容性解决方案
如需支持旧版浏览器，建议：
1. 使用Babel转译ES6代码
2. 添加polyfill
3. 降级到ES5语法

## 故障排除

### 常见问题及解决方案

#### 1. 游戏无法加载
**可能原因：**
- 文件路径错误
- 浏览器不支持ES6模块
- 跨域问题

**解决方案：**
- 使用HTTP服务器而非本地文件
- 检查浏览器控制台错误
- 确保所有文件路径正确

#### 2. Canvas不显示
**可能原因：**
- Canvas元素未正确创建
- 显卡驱动问题
- 浏览器硬件加速被禁用

**解决方案：**
- 检查浏览器支持性
- 更新显卡驱动
- 启用硬件加速

#### 3. 键盘控制无效
**可能原因：**
- 焦点不在游戏窗口
- 键盘事件被阻止
- 控制键配置错误

**解决方案：**
- 点击游戏区域获取焦点
- 检查浏览器扩展程序
- 验证控制键配置

#### 4. 高分无法保存
**可能原因：**
- localStorage被禁用
- 隐私浏览模式
- 浏览器数据清理

**解决方案：**
- 允许网站使用localStorage
- 退出隐私浏览模式
- 设置浏览器允许保存数据

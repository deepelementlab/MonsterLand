# 👾 怪兽冒险 Monster Quest

一款基于 HTML5 Canvas 的横版闯关小游戏

## 🎮 游戏特性

- **3个精心设计的关卡**：绿野森林、熔岩洞穴、天空之城
- **3种怪兽类型**：巡逻型、追踪型、跳跃型
- **丰富的游戏元素**：金币收集、钥匙解锁、平台跳跃
- **流畅的操控体验**：支持键盘控制
- **粒子特效系统**：击杀怪兽、收集物品时的视觉反馈

## 🎯 游戏目标

1. 收集关卡中的🔑钥匙
2. 躲避或击败👾怪兽（按X攻击）
3. 收集💰金币获得高分
4. 带着🔑到达🏁终点旗帜完成关卡

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| ⬅️ ➡️ 方向键 | 左右移动 |
| ⬆️ 上键 / 空格 | 跳跃 |
| X键 | 攻击（击败怪兽）|
| P键 | 暂停游戏 |

## 👾 怪兽类型

| 类型 | 颜色 | 特性 |
|------|------|------|
| 🔴 巡逻型 | 红色圆形 | 固定路线巡逻 |
| 🟣 追踪型 | 紫色方形 | 发现玩家后会追踪 |
| 🟢 跳跃型 | 绿色菱形 | 定时跳跃移动 |

## 🏆 计分系统

- 💰 金币：10分
- 👾 击杀怪兽：50分

## 🚀 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏！

```bash
# 方法1：直接打开文件
双击 index.html

# 方法2：使用本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎨 技术特点

- **纯前端实现**：HTML5 + CSS3 + JavaScript
- **Canvas渲染**：流畅的60FPS游戏画面
- **面向对象设计**：Player、Monster、Game类清晰分离
- **物理引擎**：重力、碰撞检测、平台交互
- **响应式设计**：适配不同屏幕尺寸

## 🌟 关卡介绍

### 关卡1：绿野森林（入门）
- 简单的平台布局
- 2个巡逻型怪兽
- 适合新手熟悉操作

### 关卡2：熔岩洞穴（进阶）
- 断裂的平台，需要精准跳跃
- 3个混合类型怪兽
- 追踪型怪兽增加挑战

### 关卡3：天空之城（挑战）
- 复杂的多层平台
- 4个高难度怪兽组合
- 需要熟练的操作技巧

## 💡 游戏技巧

1. **观察怪兽移动规律** - 掌握时机通过
2. **善用攻击** - X键可以消灭怪兽
3. **注意无敌时间** - 受伤后有短暂无敌
4. **收集所有金币** - 挑战最高分
5. **先拿钥匙** - 没有钥匙无法过关
